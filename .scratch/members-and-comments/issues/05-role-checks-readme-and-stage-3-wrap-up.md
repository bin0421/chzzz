### 3. 세 역할 직접 확인 (사용자와 함께)
브라우저 두 개(일반 창 = 회원 A, 시크릿 창 = 회원 B, 로그아웃 상태 = 비로그인)로 나눈다.
- [ ] 회원가입·로그인·로그아웃, 헤더 표시, 로그인 필요 화면의 리다이렉트와 복귀
- [ ] 녹화방송: A 등록 → B·비로그인에게 수정·삭제 버튼 없음 → API 직접 호출(B `403`, 비로그인 `401`) → A 수정·삭제 성공
- [ ] 라이브 방송: A가 휴대폰으로 로그인해 송출 → PC에서 B·비로그인 시청 가능, 종료 버튼 없음, API 종료 시도 거절 → A가 PC(다른 기기)에서 종료 → 종료 후 삭제
- [ ] 댓글: 비로그인 작성 불가(화면 안내, API `401`) → A·B 작성 → B가 A 댓글 수정·삭제 시도 거절(`403`) → A 수정("수정됨")·삭제 → 라이브 방송 댓글이 다른 창에 몇 초 안에 나타남
- [ ] CSRF: 토큰 헤더 없이 보낸 상태 변경 요청이 거절된다
- [ ] 1·2단계 직접 확인 절차(로그인 필요한 단계는 로그인 후)가 그대로 통과한다
