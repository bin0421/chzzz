# 04: 목록·상세 화면 마무리

**What to build:** 시청자가 목록과 상세 화면에서 길을 잃지 않는다. 등록된 녹화방송이 없으면 안내와 등록 버튼이 보이고, 목록 항목에서 출처 종류와 등록일시를 알 수 있다. 어느 화면에서든 목록과 등록으로 갈 수 있고, 없는 녹화방송이나 재생 실패 상황에서는 안내를 받는다. 스펙: `.scratch/recordings/spec.md`.

02, 03과 병행한다. 이 티켓은 목록·상세 화면과 공통 헤더만 건드리고 등록 폼은 건드리지 않는다.

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 목록이 비어 있으면 안내 문구와 등록 버튼을 보여 준다
- [ ] 목록 항목마다 제목, 등록일시(브라우저 로컬 시간), 출처 종류(업로드/URL)를 보여 준다
- [ ] 공통 헤더에 목록과 등록 링크가 있다
- [ ] 없는 녹화방송이면 백엔드가 `404` Problem Details로 응답하고(HTTP API 경계 테스트), 상세 화면은 "찾을 수 없음"과 목록 링크를 보여 준다
- [ ] 상세 화면에 제목과 등록일시가 보인다
- [ ] 플레이어에서 재생 오류 이벤트가 나면 안내 문구를 보여 준다
- [ ] 위 화면 동작이 앱 단위 테스트로 검증된다
- [ ] 모든 사이클이 `docs/tdd-log.md`에 기록되어 있다
