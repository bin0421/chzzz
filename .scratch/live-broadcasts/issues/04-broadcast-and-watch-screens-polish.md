# 04: 송출·시청 화면 마무리

**What to build:** 송출자는 휴대폰에서 방송 전에 전면·후면 카메라를 골라 미리보기로 확인하고, 문제가 생기면(권한 거부, 기기 없음, HTTPS가 아님, 연결 실패) 무엇을 해야 하는지 안내받는다. 방송 중에는 시청 화면 링크를 볼 수 있다. 시청자는 자동재생으로 소리가 막히면 "소리 켜기" 버튼으로 소리를 켜고, 연결이 실패하거나 없는 라이브 방송이면 안내를 받는다. 스펙: `.scratch/live-broadcasts/spec.md`.

02, 03, 05와 병행한다. 이 티켓은 **화면 쪽 사용성**을 맡고 백엔드는 건드리지 않는다. 송출 화면의 종료 버튼·키 보관(02)과 시청 화면의 종료·대기 처리(02, 03)는 건드리지 않는다.

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 송출 화면에서 제목 검증 메시지를 보여 준다(녹화방송 등록과 같은 규칙, 서버 `400`의 필드 오류 표시 포함)
- [ ] 전면/후면 카메라 선택이 어댑터 미리보기 요청에 전달되고, 선택을 바꾸면 미리보기를 다시 연다. 방송 중에는 바꿀 수 없다
- [ ] 어댑터가 권한 거부, 기기 없음, 보안 컨텍스트 아님(HTTPS 아님) 오류를 내면 각각 다른 안내와 해결 방법을 보여 준다
- [ ] 송출 시작 후 연결에 실패하면 네트워크·방화벽을 확인하라는 안내를 보여 준다
- [ ] 방송 중에는 시청 화면 링크(주소 포함)를 보여 준다
- [ ] 시청 화면에서 자동재생으로 소리가 막히면 음소거로 재생하고 "소리 켜기" 버튼을 보여 준다. 누르면 소리가 켜진다
- [ ] 시청 연결이 실패하면 안내를 보여 준다. 없는 라이브 방송(`404`)이면 "찾을 수 없음"과 목록 링크를 보여 준다
- [ ] 위 동작이 앱 단위 테스트(가짜 어댑터)로 검증된다
- [ ] 송출·시청 화면에 1단계 화면과 어울리는 기본 스타일이 있고, 휴대폰 폭에서 무너지지 않는다
- [ ] 모든 사이클이 기록되어 있다. 병행 중이라 `docs/tdd-log.md` 대신 이 파일의 `## TDD 기록`에 남기고, 병합할 때 옮긴다
