# TDD 기록

red → green(→ refactor) 사이클마다 한 줄씩 기록한다. 4단계까지 이어 쓰며, 최종 발표에서 TDD 과정의 근거로 쓴다.

- **테스트**: 테스트 이름
- **red**: 처음에 실패한 이유(실제 실패 메시지 요지)
- **green**: 통과시킨 최소 변경
- **refactor**: 리팩터 내용(없으면 `-`)
