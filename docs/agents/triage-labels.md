# 트리아지 라벨

스킬들은 다섯 가지 표준 트리아지 역할로 말한다. 이 파일은 각 역할을 이 저장소에서 실제로 쓰는 라벨 문자열에 대응시킨다. 로컬 마크다운 트래커이므로 라벨은 이슈 파일 맨 위의 `Status:` 줄에 적는다.

| mattpocock/skills의 라벨 | 이 저장소의 라벨 | 의미 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 검토가 필요함 |
| `needs-info` | `needs-info` | 추가 정보를 기다림 |
| `ready-for-agent` | `ready-for-agent` | 스펙 확정, 에이전트가 바로 구현 가능 |
| `ready-for-human` | `ready-for-human` | 사람이 직접 구현해야 함 |
| `wontfix` | `wontfix` | 처리하지 않음 |

스킬이 역할을 언급하면 (예: "AFK-ready 트리아지 라벨 적용") 이 표에서 대응하는 라벨 문자열을 쓴다.

실제로 쓰는 어휘가 바뀌면 "이 저장소의 라벨" 열을 고친다.
