- 로그인 없이 녹화방송(업로드 파일 또는 외부 URL)을 등록하고 목록·상세·플레이어로 시청한다. 재시작 후에도 남는다.

### 주요 결정
- 프론트 React + Vite + TS(SPA)와 백엔드 Spring Boot + Kotlin REST API 분리
- PostgreSQL + Flyway: 4단계에 걸친 스키마 변경을 버전으로 관리
- 업로드 파일은 로컬 디스크 + Range 스트리밍 (ADR-0001)
- 외부 URL은 서버에서 접속 확인하지 않음 (ADR-0002)
- 영상 출처를 "종류 + 값"으로 모델링해서 2단계 출처 추가에 대비
