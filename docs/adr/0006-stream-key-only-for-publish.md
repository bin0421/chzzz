# 송출 키는 MediaMTX 송출 허가에만 쓰고, 라이브 방송 제어는 로그인한 소유자로 검사한다

2단계에서는 로그인이 없어서 송출 키가 송출과 종료의 유일한 근거였다(ADR-0003). 3단계부터 라이브 방송은 로그인한 회원만 시작할 수 있고, 시작한 회원이 소유자가 된다. 종료·제목 수정·삭제는 백엔드가 세션의 회원이 소유자인지로 검사한다. 송출 키는 여전히 시작할 때 소유자에게 한 번만 주고 해시만 저장하지만, 쓰임은 MediaMTX가 묻는 WHIP 송출 허가 하나로 줄인다. MediaMTX의 HTTP 인증 요청에는 브라우저의 세션 쿠키가 실려 오지 않아서 송출 허가만큼은 세션으로 판단할 수 없기 때문이다.

## Considered Options

- **송출 키로 계속 종료**: 2단계 동작을 유지하지만, 키를 가진 탭에서만 종료할 수 있고 "소유자를 서버에서 검사한다"는 3단계 요구와 맞지 않는다.
- **송출 허가도 세션으로**: MediaMTX가 쿠키를 넘겨주지 않아 불가능하다. WHIP 요청에 세션 ID를 실어 보내면 세션 쿠키를 `HttpOnly`로 둘 수 없다.

## Consequences

- 소유자는 송출하던 탭을 닫았거나 다른 기기에서도 자기 라이브 방송을 종료할 수 있다. 2단계의 탭 저장소(sessionStorage) 송출 키 보관은 없앤다.
- 송출 키가 새어 나가도 할 수 있는 일은 대기 중인 그 방송에 영상을 내보내는 것뿐이고, 방송을 종료하거나 바꿀 수는 없다.
